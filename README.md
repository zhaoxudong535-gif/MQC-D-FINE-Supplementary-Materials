# MQC-D-FINE Supplementary Materials

This repository provides the supplementary materials associated with the manuscript:

**MQC-D-FINE: A Lightweight Quality-Aware Detection Framework for Accurate Chip Surface Defect Inspection in Intelligent Manufacturing**

**Journal:** Journal of Intelligent Manufacturing  
**Manuscript ID:** JIMS-D-26-03066

## Files

- **ESM_1.zip — Online Resource 1:** Study-specific chip and PCB split manifests, the original-to-harmonized label mapping, operating-point count tables, and a lightweight count-metric recomputation notebook.
- **ESM_2.pdf — Online Resource 2:** Additional experiments, sensitivity analyses, and evaluation-protocol details.

Ground-truth images and annotations are not redistributed. Access to the original public datasets is provided through the sources identified in the manuscript.

## Version

Version 1.0 corresponds to the first revised submission of manuscript JIMS-D-26-03066.
